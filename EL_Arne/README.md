# Start development environment

Projektet kräver två aktiva terminaler under utveckling:


# Available Scripts

| Script | Description |
|---|---|
| `npm run app:watch` | Startar ASP.NET med hot reload |
| `npm run css:watch` | Watch för TailwindCSS |
| `npm run css:build` | Bygger minifierad CSS |
| `npm run dev` | Startar ASP.NET utvecklingsserver |
